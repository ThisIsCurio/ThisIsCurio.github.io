# Curio site

Interactive companions for Curio videos, served by GitHub Pages.

- `index.html`: home page, one card per companion (newest first).
- `voyager/`: Light-Day Explorer (video: One Light-Day Out).
- `life-ribbon/`: Your Life Ribbon (video: Why Years Get Shorter).
- `cas9-guide-lab/`: Cas9 Guide Lab (video: Bacteria's Scissors).
- `height-clock/`: Height Clock (video: Falling Toward Slower Time).
- `assets/`: the Curio mark.

Hidden (page kept so old links work, but not on the home page):
- `radiocarbon-lab/`: Radiocarbon Lab (video: The Clock in Every Bone). Hidden 2026-11-06 at the owner's request.

To add a companion: put it in its own folder as `index.html`, add a card to the
home page, commit and push. Pages republishes in about a minute.
